개인정보처리방침

시행일: 2026년 9월 16일 · 애니노트 v1.5.2

1. 수집·처리하는 정보

  • 회원가입·로그인: 이메일 주소, 계정 식별자
  • 프로필: 아이디(username), 표시 이름, 소개
  • 서비스 이용정보: 감상, 평점, 시청 상태, 즐겨찾기, 캐릭터 방명록
  • 운영정보: 수정 요청, 신고, 문의, 활동 로그
  • 사용자가 직접 등록하는 애니·성우·캐릭터 정보 및 이미지
비밀번호 인증은 Supabase Auth를 통해 처리되며 애니노트 운영 화면에서 비밀번호 원문을 조회하지 않아.

2. 이용 목적

  • 회원 식별 및 로그인
  • 개인 감상 기록, 즐겨찾기, 통계 및 취향 추천 제공
  • 공개 프로필과 커뮤니티 기능 제공
  • 신고·수정요청 처리, 서비스 보안 및 운영 기록 관리

3. 다른 이용자에게 공개될 수 있는 정보

아이디, 표시 이름, 소개, 공개 감상, 평점, 즐겨찾기, 방명록 및 공용 DB에 등록한 정보는 서비스 내 다른 로그인 이용자에게 표시될 수 있어. 이메일 주소와 로그인 정보는 일반 이용자에게 공개하지 않아.

4. 외부 서비스 이용

애니노트는 인증·데이터베이스·파일 저장을 위해 Supabase를, 웹사이트 호스팅과 전송을 위해 Vercel을 사용해. 각 서비스 제공 과정에서 보안·운영에 필요한 기술 정보가 처리될 수 있어.

5. 보유 기간과 계정 삭제

회원 정보는 원칙적으로 계정을 사용하는 동안 보관해. 계정 삭제 요청이 처리되면 프로필, 개인 감상, 즐겨찾기, 캐릭터 평점·방명록 등 계정에 연결된 개인 데이터와 해당 이용자의 활동 로그를 정리해.
다만 애니·성우·캐릭터처럼 여러 이용자가 함께 사용하는 공용 DB 기여분은 서비스 데이터의 연속성을 위해 남을 수 있으며, 계정과의 연결 정보는 제거될 수 있어.

6. 계정 삭제 방법

로그인 → 내 프로필 → 계정 삭제 요청을 누르면 관리자에게 요청이 전달돼. 관리자가 확인 후 삭제 처리하면 계정에서 로그아웃되며 복구할 수 없어.

7. 문의·삭제 요청 방법

로그인 후 사이트 하단의 문의 버튼을 이용하거나, 계정 삭제는 내 프로필 → 계정 삭제 요청을 이용해. 버그나 서비스 문제는 하단의 빨간 버그제보 버튼으로 보낼 수 있어.

8. 방침 변경

수집 항목이나 이용 목적이 크게 바뀌는 경우 이 방침의 내용과 시행일을 갱신해 안내해.
